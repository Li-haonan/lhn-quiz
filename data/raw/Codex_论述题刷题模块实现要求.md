# 给 Codex 的实现任务：新增“论述题刷题”模块

请在现有 Vue 3 + Vite 刷题项目中新增独立的“论述题”模块，数据源使用：
`人工智能竞赛_论述题题库_Codex版.json`

## 核心交互
1. 随机/顺序出一道论述题。
2. 用户在文本框中输入答案。
3. 点击“提交评分”后立即反馈：
   - 总分（10分制）
   - 已覆盖评分点
   - 未覆盖评分点
   - 建议补充内容
4. 支持“查看参考答案”“重新作答”“下一题”。
5. 记录每题历史最好成绩、作答次数、最近一次得分和掌握状态。
6. 增加“错题/薄弱题”入口，可按低分优先复习。

## 评分规则
- 不做逐字匹配。
- `scoring.key_points` 是主要评分依据，判断用户是否在语义上覆盖该得分点。
- `scoring.keywords` 只用于快速本地提示，不能因为没写完全相同的词就判错。
- 静态部署时可先实现“关键词 + 同义词 + 覆盖率”的本地评分。
- 如果后续接入大模型语义评分，API Key 禁止写入前端代码或 GitHub Pages；必须通过后端/Serverless 代理。
- AI 评分返回结构建议固定为：
  `{score, hit_points, missed_points, feedback}`。

## 三种模式
- 速背模式：只写关键词/提纲，快速判断评分点覆盖。
- 论述模式：写完整答案，给10分制反馈。
- 模拟考试：随机抽题，不立即展示参考答案，结束后统一统计。

## UI
尽量复用现有选择题页面的视觉风格和进度系统，不单独做另一套完全不同的页面。
